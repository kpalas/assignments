# 📄 Research Papers Directory

## 🎯 Overview
This iOS application serves as a clean, structured directory for browsing academic research papers. It demonstrates strong proficiency in handling data models, dynamic table views, and view controller navigation.

## 🌟 Key Features
* **Dynamic Data Rendering:** Uses a custom `UITableViewController` (`ResearchPapersTVC.swift`) to dynamically render a list of academic papers based on a structured Swift data model.
* **Custom Data Models:** Employs a dedicated `dataModel.swift` file to cleanly separate the app's raw data (paper titles, authors, abstracts) from the UI logic.
* **Detail Navigation:** Users can tap on a specific research paper to trigger a segue, passing the selected data object to a detail view for deeper reading.

## 🛠️ Technical Stack
* **Language:** Swift 5
* **Framework:** UIKit
* **UI Components:** `UITableView`, Navigation Controllers, Storyboard Segues
* **Architecture:** MVC

## 🚀 How to Run
1. Open `Research Papers.xcodeproj` in Xcode.
2. Select your preferred iOS Simulator.
3. Press `Cmd + R` to build and run.
