# PHP & MySQL Tutorial Management System

## 🎯 Overview
This project is a dynamic, full-stack web application designed to manage and display tutorial data. It demonstrates core backend web development concepts by integrating a PHP frontend with a MySQL relational database.

## Technical Concepts Demonstrated
* **Full-Stack Integration:** Established secure connections between a PHP server environment and a MySQL database to serve dynamic content.
* **Database Design:** Designed and populated a relational database (`COMP284-CA1-sgkpalas.sql`) with structured schema definitions and seed data.
* **Server-Side Scripting:** Utilized PHP to query the database, process the retrieved data, and dynamically render HTML to the client.
* **Data Management:** Handled data extraction and presentation logic, ensuring a clean separation between the database layer and the presentation layer.

## 🚀 Technologies Used
* **Backend:** PHP
* **Database:** MySQL 
* **Frontend:** HTML/CSS (rendered via PHP)
